## Съгласуване с личните отчети
Личните отчети са предоставени от потребителя. Уточнено е, че UNIQUE(era_id) допуска най-много една награда за епоха, а наличието на точно една се проверява в началните данни. Номерата на локалните задачи не са потвърдени GitHub Issue номера. Линкове към профили и commits още не са предоставени.
