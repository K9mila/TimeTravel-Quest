# План за тестове
Статус: планирани, не изпълнени. Чистите алгоритми се проверяват с Vitest; Auth/RLS и записите — интеграционно в отделни тестови профили.

| ID | Проверка | Очакван резултат |
|---|---|---|
| T01 | Хронология [-500,-100,800] | Валидна |
| T02 | Хронология [-100,-500,800] | Посочена нарушена двойка |
| T03 | Дублирано ID | Невалиден вход |
| T04 | Липсващо или непознато ID | Невалиден вход |
| T05 | Равни години | И двата реда при равенство са валидни |
| T06 | Празна задача или година 0 | Невалиден вход |
| T07 | Два верни първи отговора | Нивото се повишава с 1 |
| T08 | Два грешни първи отговора | Нивото се понижава с 1 |
| T09 | Ниво вече е 1 или 3 | Не излиза извън границите |
| T10 | Няма въпрос на желаното ниво | Най-близкото налично; по-лесното при равенство |
| T11 | Верен след подсказка или повторен опит | Не увеличава успешната поредица |
| T12 | Недостатъчна банка | Ясно съобщение, без безкраен цикъл |
| T13 | Повторно завършване/двойно изпращане | Само един артефакт; без двоен напредък |
| T14 | Изход и нов вход | Възстановени задачи и ниво |
| T15 | Прекъсната връзка при запис | Грешка и повторен опит; без фалшиво потвърждение |
| T16 | A чете или редактира B | Отказ |
| T17 | Играч пише директно награда/съдържание | Отказ |
| T18 | Нулиране | Само личните записи се премахват |
| T19 | 360 px и клавиатура | Достъпни действия, без страничен скрол |
| T20 | Невалидна регистрация | Четимо съобщение, без успешен вход |

Потребителска проверка в седмица 5: 3–5 ученици опитват старт, една мисия, намиране на предмет и хронология без подсказване от разработчиците. Записваме анонимни затруднения, поправките и повторна проверка. Не публикуваме данни на деца или пароли от лични профили.
